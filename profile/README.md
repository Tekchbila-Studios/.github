# Tekchbila Studios

A small independent studio building tools that make infrastructure legible.

Terraform tells you what will change. It does not tell you what it will *look*
like afterwards. That gap — between a plan you can read line by line and a
system you can hold in your head — is what we build for.

## What we're working on

**[Infragr.am](https://infragr.am)** — architecture diagrams generated from your
Terraform plan. Point it at a plan, get a diagram of what that plan produces.
Secrets are stripped before anything leaves your runner.

## How we work

- **Infrastructure as code, all the way up.** This organization's own settings —
  membership defaults, repository inventory, branch protection, even the page
  you are reading — are Terraform. Changing org policy means opening a pull
  request.
- **Private by default.** Repositories here are private unless there is a stated
  reason to publish. Nothing becomes public by accident.
- **Squash merges, linear history.** One commit per change, and the commit
  message explains *why*, since the diff already covers *what*.
